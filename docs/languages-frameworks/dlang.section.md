# D (Dlang) {#dlang}

Nixpkgs oferece múltiplos compiladores D, como `ldc` e `dmd`.
Estes podem ser usados como qualquer outro pacote durante o tempo de compilação.

No entanto, Nixpkgs oferece um auxiliar de compilação para compilar pacotes usando o gerenciador de pacotes `dub`.

Aqui está um exemplo:
```nix
{
  lib,
  buildDubPackage,
  fetchFromGitHub,
  ncurses,
  zlib,
}:

buildDubPackage rec {
  pname = "btdu";
  version = "0.5.1";

  src = fetchFromGitHub {
    owner = "CyberShadow";
    repo = "btdu";
    tag = "v${version}";
    hash = "sha256-3sSZq+5UJH02IO0Y1yL3BLHDb4lk8k6awb5ZysBQciE=";
  };

  # generated by dub-to-nix, see below
  dubLock = ./dub-lock.json;

  buildInputs = [
    ncurses
    zlib
  ];

  installPhase = ''
    runHook preInstall
    install -Dm755 btdu -t $out/bin
    runHook postInstall
  '';
}
```

Observe que você precisa definir `installPhase` porque `dub` não sabe para onde os arquivos devem ir em `$out`.

Observe também que a execução de `dub test` está desabilitada por padrão. Você pode habilitá-la definindo `doCheck = true`.

## Lockfiles {#dub-lockfiles}
Nixpkgs tem seu próprio formato de lockfile para dependências `dub`, porque o formato "lockfile" oficial do `dub` (`dub.selections.json`) não é baseado em hash.

Um lockfile pode ser gerado usando o pacote auxiliar `dub-to-nix`.
* Primeiro, instale `dub-to-nix` em sua sessão shell executando `nix-shell -p dub-to-nix`.
* Em seguida, navegue até a raiz do código-fonte do programa que você deseja empacotar.
* Finalmente, execute `dub-to-nix`, e ele imprimirá o lockfile para a saída padrão (stdout). Você pode redirecionar a saída padrão para um arquivo de texto ou apenas copiar a saída manualmente para um arquivo.

## Parâmetros de `buildDubPackage` {#builddubpackage-parameters}

A função `buildDubPackage` recebe um attrset de parâmetros que são passados para `stdenv.mkDerivation`.

Os seguintes parâmetros são específicos para `buildDubPackage`:

* `dubLock`: Um lockfile gerado por `dub-to-nix` a partir do código-fonte do pacote. Pode ser um caminho para o arquivo, ou um attrset já analisado com `lib.importJSON`.
  Este último é útil se o pacote usa dependências `dub` que ainda não estão no lockfile. (por exemplo, se o pacote chama `dub run some-dub-package` manualmente)
* `dubBuildType ? "release"`: O tipo de compilação a ser passado para `dub build` como um valor para a flag `--build=`.
* `dubFlags ? []`: As flags a serem passadas para `dub build` e `dub test`.
* `dubBuildFlags ? []`: As flags a serem passadas para `dub build`.
* `dubTestFlags ? []`: As flags a serem passadas para `dub test`.
* `compiler ? ldc`: O compilador D a ser usado por `dub`.

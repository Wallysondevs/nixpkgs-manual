# Abrindo issues {#sec-opening-issues}

*   Certifique-se de ter uma [conta GitHub](https://github.com/signup/free)
*   Certifique-se de que não há nenhuma issue aberta sobre o tópico
*   [Envie uma nova issue](https://github.com/NixOS/nixpkgs/issues/new/choose) escolhendo o tipo de tópico e preenchendo o modelo

# nodejsInstallManuals {#nodejs-install-manuals}

Detecta manuais em pacotes Node.js e tenta instalá-los em locais padrão.
Esta detecção é feita inspecionando o `package.json` do projeto e encontrando quaisquer entradas
com o tipo `man`.

Atualmente não há maneiras de configurar este hook.
